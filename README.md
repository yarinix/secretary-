# Secretary Bot

Секретарь для Telegram Business: **пересылает вам копию каждого входящего сообщения** и отвечает клиенту в ваших личных чатах от вашего лица. Если вы сами ответили в чате, бот там временно замолкает.

## Как работает

- Клиент пишет → вы получаете `📨` с копией → бот отвечает через каскад моделей Gemini → вы получаете `🤖` с копией ответа (можно отключить).
- Копия входящего приходит **всегда**, даже если автоответы выключены, бот на паузе, сработал лимит, нет права отвечать или не задан ключ ИИ.
- Обрабатываются текст, подписи, голосовые, видеосообщения (кружки) и фото. Стикеры и документы не отвечаются, но копия входящего приходит.
- Управление в личке с ботом: `/business on|off`, `/business inbox on|off`, `/business notify on|off`, `/business persona <текст>`, `/business persona clear`, `/business status`.
- Логика перенесена из [ForUs](https://github.com/yarinix/ForUs-) (`tgbot/business.py`, `tgbot/llm.py`): пауза при вашем вмешательстве (`BUSINESS_TAKEOVER_MINUTES`, 60), лимит ответов в час на чат (`BUSINESS_MAX_REPLIES_PER_HOUR`, 20), защита от инъекций в промпте, каскад моделей.

### Каскад моделей

Тот же, что в ForUs: `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite`. При `429` / исчерпании квоты бот сразу переходит к следующей модели; при временных сбоях (5xx, таймаут, обрыв связи) делает до 3 попыток на той же модели; пустой ответ считается неудачей. Список переопределяется через `GEMINI_MODELS` (модели через запятую). SDK `google-genai` не нужен — запросы идут через уже имеющийся `aiohttp`.

> **Про `ANTHROPIC_API_KEY`:** Claude не подключён. Название переменной оставлено исторически (в Render уже так задано, переименовывать лень) — **в ней лежит ключ Gemini**. Можно дополнительно задать «правильное» имя `GEMINI_API_KEY`: если заданы оба, приоритет у `GEMINI_API_KEY`. Код вызовов `api.anthropic.com` удалён.

Если ключа нет вообще, бот **не отправляет собеседнику ничего**: сообщение «от лица владельца» о технической ошибке выглядело бы странно. Вы просто получите копию входящего и сможете ответить сами.

## Подключение

1. @BotFather → `/newbot`; затем Bot Settings → Business Mode → включить.
2. Нужен Telegram Premium. Настройки → Telegram для бизнеса → Чат-боты → выбрать бота, оставить право отвечать на сообщения.
3. Узнайте свой числовой ID (@userinfobot) и задайте `OWNER_ID` — **обязательно**. Бот не запустится без него: больше никто не сможет захватить управление через `/start`.
4. Задеплоить на Render (New → Blueprint → этот репозиторий), заполнить переменные.

## Переменные окружения

| Переменная | Обязательная | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `OWNER_ID` | **да** | ваш числовой Telegram ID |
| `ANTHROPIC_API_KEY` | нет | **ключ Gemini** (историческое название, см. выше) |
| `GEMINI_API_KEY` | нет | «правильный» алиас; приоритет над `ANTHROPIC_API_KEY` |
| `GEMINI_MODELS` | нет | каскад через запятую; по умолчанию `gemini-3.5-flash-lite,gemini-3.1-flash-lite` |
| `WEBHOOK_SECRET` | нет | секрет вебхука; если не задан, берётся хэш от `BOT_TOKEN` (не «change-me») |
| `WEBHOOK_BASE_URL` | нет | базовый URL вебхука; если не задан, используется автоматический `RENDER_EXTERNAL_URL` |
| `OWNER_NAME` | нет | как зовут владельца в промпте (по умолчанию «владельца») |
| `BOT_TIMEZONE` | нет | часовой пояс для времени в промпте (по умолчанию `Asia/Omsk`) |
| `BUSINESS_TAKEOVER_MINUTES` | нет | пауза после вашего сообщения, 60 |
| `BUSINESS_MAX_REPLIES_PER_HOUR` | нет | лимит ответов на чат, 20 |
| `BUSINESS_IGNORE_IDS` | нет | ID через запятую, кому бот не отвечает (например, близким) |
| `DB_PATH` | нет | путь к SQLite, по умолчанию `secretary.db` |
| `PORT` | нет | порт, по умолчанию 10000 |

Все пользовательские переменные объявлены в `render.yaml`; `WEBHOOK_SECRET` генерируется Render автоматически. `RENDER_EXTERNAL_URL` Render подставляет сам — если его не окажется, бот поднимется, но запишет предупреждение в лог и не получит обновления (поллинг-фолбэка нет).

> На бесплатном плане Render диск временный: настройки, история, паузы и счётчики лимитов сбрасываются при перезапуске. Для постоянного хранения задайте `DB_PATH` на подключённый диск.

## Разработка

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Тесты покрывают чистые функции, сборку `contents` для Gemini и SQLite-хранилище; aiogram, сеть и `BOT_TOKEN` им не нужны.

Структура: `config.py` (валидация окружения), `helpers.py` (чистые функции), `storage.py` (SQLite), `llm.py` (каскад Gemini), `main.py` (aiogram-обработчики и webhook).
